# Entrevista Inicial - Módulo de Comunicación con el Cliente

### Preguntas Propuestas: 

1. ¿Actualmente, cuáles son los canales principales por los que los clientes se contactan con la empresa y en cuál sienten que pierden más tiempo o control?

**Respuesta:** Actualmente los clientes se contactan principalmente por WhatsApp, llamadas telefónicas, TikTok, Instagram, Facebook y la página web. Anteriormente las llamadas eran el medio principal, pero ahora las redes sociales tienen mucha importancia. También muchos clientes llegan por recomendación de otras personas. Se busca centralizar mejor la comunicación mediante un sistema.

2. Cuando un cliente hace una solicitud, cotización o reclamo, ¿cuál es el paso a paso exacto que sigue su equipo para darle respuesta y en dónde registran ese seguimiento?

**Respuesta:** Cuando un cliente está interesado, puede solicitar una cotización. Un operador acude a la vivienda u obra para revisar lo necesario y posteriormente se realiza la cotización final. Durante el proceso se generan reportes y fotografías del avance. Parte de esta información se registra en el sistema que utilizan actualmente.

3. ¿Cómo se registra actualmente la información y el historial de las conversaciones o solicitudes de cada cliente para poder darles seguimiento?

**Respuesta:** Actualmente cuentan con un sistema al que los usuarios acceden mediante correo y contraseña. En este sistema pueden consultar información del prroyecto, avances y fotografías. También parte de la comunicación se realiza por WhatsApp, llamadas y redes sociales. 

4. ¿Qué dificultades se presentan con mayor frecuencia al dar seguimiento a las solicitudes de los clientes y cómo las solucionan actualmente?

**Respuesta:** Una de las principales áreas de oportunidad es que la comunicación se realiza por diferentes medios, como WhatsApp, llamadas y redes sociales. Para dar seguimiento utilizan el sistema y los reportes fotográficos que se generan durante el proyecto. También se busca que el cliente pueda consultar directamente el avance de su proyecto.

5. ¿Cómo determinan actualmente si una solicitud de un cliente ya fue atendida y quién es responsable de darle seguimiento?
 
**Respuesta:** El seguimiento se realiza mediante el personal encargado de atender al cliente y mediante el sistema. Cuando se realiza una visita a la vivienda u obra, el operador genera la información necesaria para continuar con la cotización. Actualmente, quienes responden las consultas son principalmente ingenieros.

6. ¿Cómo se asignan actualmente las solicitudes de los clientes entre los diferentes integrantes o áreas del equipo, y qué sucede cuando una solicitud necesita ser atendida por más de una persona?

**Respuesta:** En la entrevista no se explicó de manera específica cómo se asignan las solicitudes entre las diferentes áreas. Sin embargo, participan diferentes personas, como operadores e ingenieros, dependiendo de las necesidades del proyecto. Este es un aspecto que podría organizarse mejor dentro del sistema.

7. ¿Qué información consideran indispensable tener disponible al momento de atender a un cliente para poder darle una respuesta rápida y adecuada?

**Respuesta:** Es importante contar con información como el precio final, el avance del proyecto, fotografías del progreso, presupuesto, programación de juntas, cantidad de operativos que trabajan por semana, fichas técnicas, garantías, certificaciones y términos y condiciones. También es importante mostrarle al cliente qué tiene que pagar y en qué momento.

8. ¿Cuentan con tiempos máximos de respuesta (SLA) definidos para cada tipo de solicitud y cómo miden si el equipo está cumpliendo con esos tiempos?

**Respuesta:** Actualmente el tiempo aproximado de respuesta es de 12 horas por mensaje. Las personas encargadas de responder trabajan de lunes a sábado de 8:00 a 18:00 horas. No se mencionaron diferentes tiempos establecidos dependiendo del tipo de solicitud.

9. ¿Utilizan actualmente alguna herramienta, plantilla de correo o respuestas automatizadas para agilizar la atención de las preguntas más repetitivas?

**Respuesta:** Existe interés en utilizar respuestas automáticas para las preguntas más frecuentes. La idea es que las dudas sencillas puedan resolverse automáticamente y que, cuando el cliente tenga una pregunta más específica o complicada, pueda comunicarse directamente con una persona.

10. Una vez que se da por resuelta una solicitud o queja, ¿tienen algún mecanismo para evaluar el nivel de satisfacción del cliente con la atención recibida?

**Respuesta:** Durante la entrevista no se mencionó un mecanismo específico para medir la satisfacción del cliente después de resolver una solicitud o queja. Por lo tanto, podría considerarse una oportunidad para implementar una encuesta o algún sistema de evaluación dentro de la plataforma.

11. ¿Qué tipo de solicitudes o consultas reciben con mayor frecuencia por parte de los clientes y cuáles consideran que requieren mayor atención?

**Respuesta:** Una de las solicitudes principales son las cotizaciones. Los clientes pueden estar interesados en diferentes productos, como vidrios, espejos, mosquiteros y mosquiteros enrollables. También pueden solicitar modificaciones a una cotización, en cuyo caso se realiza una nueva cotización.

12. ¿Existen situaciones en las que se pierda información importante durante la comunicación con un cliente, y cuáles suelen ser las principales causas?
**Respuesta:**  No se mencionó directamente un caso específico de pérdida de información. Sin embargo, debido a que la comunicación se realiza por diferentes medios, como WhatsApp, llamadas, redes sociales y página web, existe la necesidad de centralizar la información para facilitar el seguimiento de cada cliente.

13. ¿Qué mejoras consideran más importantes en el proceso actual de comunicación con los clientes para facilitar el trabajo del equipo y brindar una mejor atención?
**Respuesta:** Se propone crear una interfaz exclusiva para el cliente donde pueda consultar de manera sencilla el avance de su proyecto, fotografías, presupuesto, pagos y fechas importantes. También se busca integrar facturas, contratos, términos y condiciones y permitir que los pagos puedan realizarse directamente desde el sistema. Además, sería útil contar con respuestas automáticas para preguntas frecuentes y mantener atención personalizada para dudas más complejas. La plataforma debería estar disponible en español e inglés

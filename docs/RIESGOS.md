# Registro de Riesgos

| ID | Riesgo | Causa | Consecuencia | Probabilidad | Impacto | Respuesta | Responsable |
|---|---|---|---|---|---|---|---|
| R-01 | Falta de información por parte del cliente | El cliente puede no proporcionar a tiempo los requisitos e información necesaria para desarrollar el módulo. | El equipo puede retrasar el desarrollo o implementar funciones que no cumplen con las necesidades del cliente. | Media | Alto | Realizar reuniones de seguimiento y establecer fechas límite para solicitar y validar la información. | Responsable del producto |
| R-02 | Cambios en los requerimientos | El cliente puede solicitar cambios en las funcionalidades después de haber iniciado el desarrollo. | El equipo puede tener que modificar trabajo realizado y retrasar otras tareas del ciclo. | Media | Alto | Registrar los cambios como nuevas tareas y priorizarlos antes de modificar las funcionalidades existentes. | Responsable del producto |
| R-03 | Integración incorrecta con el sistema existente | El nuevo módulo puede presentar incompatibilidades con las funciones que ya existen en el proyecto. | Algunas funciones pueden dejar de funcionar correctamente o generar errores. | Media | Alto | Realizar pruebas de integración antes de incorporar los cambios al sistema principal. | Equipo de desarrollo |
| R-04 | Falta de tiempo para realizar pruebas | El equipo puede dedicar demasiado tiempo al desarrollo y dejar pocas horas para probar el módulo. | Pueden llegar errores al producto final y afectar la comunicación con el cliente. | Alta | Alto | Reservar tiempo de la iteración para realizar pruebas y corregir errores antes de la demostración. | Facilitador del trabajo |
| R-05 | Errores en el envío de mensajes | La implementación de la comunicación puede contener errores en el envío o recepción de mensajes. | Los mensajes pueden no llegar correctamente al cliente o al equipo. | Media | Alto | Realizar pruebas de envío y recepción de mensajes con diferentes casos antes de entregar la funcionalidad. | Equipo de desarrollo |
| R-06 | Interfaz poco clara para el cliente | El diseño puede no representar correctamente las necesidades del usuario final. | El cliente puede tener dificultades para encontrar o utilizar las funciones de comunicación. | Media | Medio | Revisar los diseños con el responsable del producto y realizar pruebas de usabilidad antes de implementar la interfaz. | Responsable del producto |
